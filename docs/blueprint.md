# **App Name**: PixelCanvas Portfolio

## Core Features:

- Dynamic Portfolio Display: Render Marvin's professional profile, skills, projects (web and video), client testimonials, and resume/certificates on the frontend, featuring auto-type animation for the 'About' section and clickable contact icons (GitHub, Facebook, Instagram, Email).
- Contact Form & Message Storage: Allows visitors to send messages through a contact form, which are then stored for Marvin to view in the admin dashboard and an email notification sent to orasco.marvin.paul@gmail.com.
- Secure Admin Authentication: Provides a protected login for Marvin to access the administrative dashboard securely, allowing content modifications without code changes.
- CMS for Core Sections: An intuitive admin interface to create, edit, and delete text content for the 'About', 'Professional Roles', 'Skills', and 'Client Feedback' sections, ensuring real-time updates on the frontend.
- Project & Media Manager: Enables Marvin to add new projects (web or video) with names, descriptions, and technologies used, upload associated images and videos, and edit/delete existing project details and media directly from the dashboard.
- Resume & Certificate Uploader: Allows Marvin to upload downloadable PDF resumes and image-based certificates (including automatic updates when changed) directly via the dashboard.
- AI Text Refinement Tool: Integrates a generative AI tool within the admin dashboard to assist Marvin in refining project descriptions, 'About' section content, or skill summaries for enhanced impact and clarity through a rewriting tool.

## Style Guidelines:

- Color Palette: A warm and earthy scheme.
- Primary Color: E4BB4F (a golden yellow), providing a bright and inviting feel.
- Secondary Color: CA7A28 (a rich orange), used for accents and interactive elements.
- Tertiary Color: 8E3D03 (a deep brown), adding depth and grounding to the design.
- Neutral Color: 535955 (a muted gray), serving as a versatile background or text color.
- Headline Font: 'Space Grotesk' (sans-serif) for a modern, slightly tech-inspired, and impactful appearance.
- Body Font: 'Inter' (sans-serif) for its highly legible, objective, and contemporary feel, suitable for detailed content and descriptions.
- Use a consistent set of minimalist, line-based vector icons for contact links, skills, and UI actions, enhancing the modern and clean aesthetic.
- Employ a clean, sectioned, and responsive layout with generous white space. Projects and testimonials will be presented in a card-based structure for visual organization on all screen sizes.
- Incorporate subtle animations for element transitions and hover states, alongside the requested auto-typing effect for the 'About' section content, to create a dynamic and engaging user experience.
