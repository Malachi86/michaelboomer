# **App Name**: Lumina Academy

## Core Features:

- AI Lesson Assistant: An intelligent course generation tool that uses reasoning to draft comprehensive lesson outlines and assessments based on instructor prompts.
- Knowledge Dashboard: A clean and organized learner interface for navigating enrolled courses and upcoming deadlines.
- Course Creator Portal: A centralized interface for instructors to manage content and edit course structures.
- Centralized Database Storage: Management of student records, course metadata, and completion status using a robust backend system.
- Interactive Student Progress: Visual progress bars and achievement tracking that update as students complete specific modules.
- Learner Registration Hub: A database-powered system for managing user roles, enrollments, and course access levels.
- Academic Community Threads: A database-backed discussion forum for each course to facilitate peer-to-peer learning.

## Style Guidelines:

- Primary color: A sophisticated Deep Scholar Blue (#2942A3) that evokes trust and academic excellence.
- Background color: A serene and clean Off-White (#F2F3F7) to maintain focus during long learning sessions.
- Accent color: A vibrant Cyan-Sky (#1FB5FF) used for calls to action and highlighting key student achievements.
- A pairing of 'Alegreya' for serif headlines to convey an intellectual feel, and 'Inter' as the sans-serif body font for its machined objectivity and readability.
- A set of thin-line icons reflecting educational motifs like books, compasses, and lightbulbs.
- A distraction-free 'zen-mode' dashboard layout with a collapsible sidebar for course navigation.
- Soft-fade transitions between lesson modules to create a sense of calm and fluid progress.
